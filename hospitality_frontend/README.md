# Hospitality AI Caller Frontend

React frontend for restaurant order management and analytics.

## Setup

1. Install dependencies using bun:
```bash
cd hospitality_frontend
bun i
```

2. Create `.env` file:
```bash
VITE_API_URL=http://localhost:8001
```

3. Run the development server:
```bash
bun dev
```

The frontend will run on port 5173 by default.

## Features

- **Orders Page**: View pending orders and completed orders for today
- **Call History**: View all inbound calls with transcripts
- **Analytics**: Restaurant analytics with charts and graphs
- **Custom Data Upload**: Upload custom data files (CSV, JSON, text)
